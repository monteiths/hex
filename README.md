# Hex Lab

Three interactive, self-contained activities for teaching two-digit hexadecimal (00–FF):

1. **Count in hex** — play, pause, next, back, reset and adjustable animation speed. Shows place values and decimal total.
2. **Teacher reveal** — random hex number with the answer hidden until **Show answer**, then a worked conversion.
3. **Student challenge** — random hex number, student enters a decimal answer, gets feedback and a worked solution. Tracks score.

Open `index.html` in any modern browser. No dependencies, accounts or internet required.

## Publish with GitHub Pages

Create a public repository called `hex`, upload `index.html` and `README.md` to the `main` branch, then in **Settings → Pages**, choose **Deploy from a branch**, `main` and `/ (root)`. The website will be at `https://YOUR-USERNAME.github.io/hex/`.
