1. Count in hexadecimal

Watch the two digits count from 00 to FF. After 9 comes A, B, C, D, E, F, then the digit resets to 0 and the next place increases.

Normal
Each hex digit can represent 16 values: 0–9 and A–F. The right-hand digit counts ones; the left-hand digit counts sixteens.

2. Teacher reveal

Generate a hexadecimal number and ask the class to calculate its decimal value. Reveal the answer only when everyone is ready.

Decimal total:
Example: 2B = (2 × 16) + (11 × 1) = 43. The letter B represents eleven.

Why hexadecimal?

One hex digit represents four binary bits. Two hex digits represent one byte (8 bits).
